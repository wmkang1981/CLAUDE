# B.Partners Pick

인스타 프로필 링크에 걸어 두는 **상품 모음 홈페이지**예요.

- **손님 화면** (`/`): 휴대폰 세로 화면. 사진을 누르면 쿠팡이나 네이버 구매 페이지로 넘어가요. 번호나 상품명으로 찾을 수 있어요.
  - **왼쪽**에 포스트잇 모양 카테고리 버튼이 세로로 붙어 있고, 누르면 **오른쪽**에 그 카테고리 상품이 2줄로 보여요.
  - 검색할 때는 카테고리와 상관없이 **전체 상품**에서 찾아요.
  - 클릭 수는 **관리자 화면에서만** 보여요. 손님 화면에는 나오지 않고, 손님용 데이터에도 들어 있지 않아요.
- **관리자 화면** (`/admin`): PC 화면이에요. 왼쪽에 휴대폰 미리보기가 있고, 오른쪽에서 상품을 등록하거나 고쳐요.

---

## 🧰 무엇으로 만들었나요?

| 역할 | 쓰는 것 | 비용 |
|---|---|---|
| 홈페이지와 관리자 기능 | Cloudflare **Workers** | 무료 (하루 요청 10만 번까지) |
| 상품 정보 저장 | Cloudflare **D1** | 무료 (500MB) |
| 상품 사진 저장 | Cloudflare **KV** | 무료 (1GB. 사진 1장이 약 0.1~0.3MB라 수천 장까지 괜찮아요) |

> 사진 저장소로 R2도 있지만, R2는 무료라도 **카드 등록이 필요**해서 KV를 골랐어요.
> 손님이 한 번 들어오면 페이지 1번과 화면에 보이는 사진 수만큼 요청이 생겨요. 무료 한도(하루 10만)를 넘을 만큼 손님이 많아지면 유료(월 $5) 전환을 생각해 보세요.

## 🚀 인터넷에 올리기 (처음 한 번만)

### 1) Cloudflare 가입
1. https://dash.cloudflare.com/sign-up 에 들어가서 이메일로 가입해요.

### 2) GitHub 저장소 연결해서 올리기
1. Cloudflare 화면 **왼쪽 메뉴**에서 **Workers & Pages**(Compute 안에 있을 수도 있어요)를 눌러요.
2. 오른쪽 위 **Create application** 버튼을 눌러요.
3. **Import a repository** 옆 **Get started**를 눌러요.
4. GitHub 계정을 연결하고, 저장소 목록에서 **CLAUDE**를 골라요.
5. 설정 칸은 이렇게 채워요.
   | 칸 이름 | 넣을 값 |
   |---|---|
   | Project name (Worker 이름) | `bpartners-pick` ← 꼭 이 이름이어야 해요 |
   | Git branch | 이 코드가 있는 브랜치 (`claude/laughing-curie-vo9uck`, main에 합친 뒤에는 `main`) |
   | Root directory | `projects/bpartners-pick` |
   | Build command | `npm run build` |
   | Deploy command | `npx wrangler deploy` (기본값 그대로) |
6. **Save and Deploy**를 눌러요. 1~3분쯤 기다려요.
   - 처음 올릴 때 상품 정보 저장소(D1)와 사진 저장소(KV)가 **자동으로 만들어져요**.
   - 실패하면 화면의 빨간 기록(build log)을 복사해서 Claude에게 보여주세요.

### 3) 관리자 비밀번호 정하기 (꼭 해야 해요!)
1. **Workers & Pages** → 목록에서 **bpartners-pick**을 눌러요.
2. 위쪽 탭에서 **Settings**를 눌러요.
3. **Variables and Secrets** 칸의 **Add** 버튼을 눌러요.
4. Type은 **Secret**으로 고르고, 나머지를 이렇게 넣어요.
   - Variable name: `ADMIN_PASSWORD`
   - Value: 나만 아는 **긴 비밀번호** (12자 이상 추천)
5. **Deploy**를 눌러요.

### 4) 내 주소 확인
- **bpartners-pick** 화면에 `https://bpartners-pick.<내계정>.workers.dev` 주소가 보여요.
  - 손님 화면: 그 주소 그대로
  - 관리자 화면: 주소 뒤에 `/admin`을 붙여요

### 5) 인스타 프로필에 링크 넣기
인스타 앱 **오른쪽 아래 내 프로필 사진** → **프로필 편집** → **링크** → **외부 링크 추가** → 주소 붙여넣기 → 저장

## ✏️ 관리자 화면 사용법

1. `/admin`에 들어가서 비밀번호로 로그인해요.
2. 오른쪽 **＋ 새 상품 추가** 칸을 누르거나, 그 칸으로 사진을 끌어다 놓아요.
3. **① 구매 링크**: 파트너스에서 만든 링크를 붙여넣어요.
   - 쿠팡인지 네이버인지 자동으로 알아봐요.
   - **링크에서 사진·이름 가져오기** 버튼을 누르면 링크의 대표 사진과 이름을 가져오려고 해요. (아래 "알아두세요" 참고)
4. **② 사진**: 사진을 넣는 방법은 네 가지예요.
   - 사진 파일을 칸 안으로 끌어다 놓기
   - 칸을 클릭해서 파일 고르기
   - 복사한 사진을 **Ctrl+V**로 붙여넣기
   - 쇼핑몰 탭에 있는 상품 사진을 바로 끌어오기
5. 사진이 들어가면 **마우스로 끌어서 위치를 옮기고**, **휠이나 막대로 확대·축소**해요.
   - **꽉 채우기**: 칸을 빈틈없이 채워요
   - **전체 보이기**: 사진 전체가 칸 안에 다 보여요
   - 고치는 대로 **왼쪽 휴대폰 화면에 바로** 보여요.
6. 번호를 적고, **카테고리 포스트잇**을 하나 고르고, 상품 이름을 적은 뒤 **💾 저장하기**를 눌러요.
7. 목록 왼쪽 **☰**를 잡고 위아래로 끌면 진열 순서가 바뀌어요.
8. **🏷️ 카테고리** 탭에서 왼쪽 포스트잇을 관리해요.
   - **＋ 카테고리 추가**: 새 포스트잇을 만들어요. 이름 칸에 글자(최대 12자)를 적어요.
   - **동그란 색 버튼**: 포스트잇 색을 골라요. 🎨를 누르면 원하는 색을 직접 고를 수 있어요.
   - **☰ 끌기**: 순서를 바꿔요. / **삭제**: 포스트잇을 지워요 (안에 있던 상품은 지워지지 않고 "전체"에서만 보여요).
   - 다 고친 뒤 **💾 카테고리 저장하기**를 눌러야 손님 화면에 반영돼요.
9. **⚙️ 사이트 설정** 탭에서 사이트 이름, 소개 문구, 수수료 안내 문구를 바꿀 수 있어요.

---

## ⚠️ 알아두세요

- **링크에서 사진 자동 가져오기는 실제로 해봐야 알아요.** 쿠팡과 네이버는 로봇 접속을 막는 경우가 많아서 실패할 수 있어요. 그래서 개발 환경에서는 시험해 보지 못했어요. 실패하면 사진을 직접 넣어주세요 (끌어다 놓기 또는 Ctrl+V).
- **쿠팡 파트너스 API**로 사진을 받는 방법도 있지만, 판매 실적 조건(최종 승인)이 있다고 알려져 있어요. 승인을 받은 뒤에 추가할 수 있어요.
- **수수료 안내 문구**는 지우지 마세요. 공정위 지침과 쿠팡 파트너스 규정 때문에 꼭 보여야 해요.
- 일반 쿠팡 주소(`www.coupang.com/...`)를 넣으면 경고가 떠요. 파트너스 링크(`link.coupang.com/...`)를 넣어야 수수료가 들어와요.

## 🧑‍💻 개발자용

```bash
npm install
echo 'ADMIN_PASSWORD=test1234' > .dev.vars   # 내 PC에서 시험할 때만 쓰는 비밀번호
npm run preview        # 만들고(build) 내 PC에서 실행 → http://localhost:8787 , /admin
npm run typecheck      # 코드 검사
```

- `src/shared/SiteView.tsx`: 손님 화면. 관리자 미리보기도 **같은 코드**를 써서 보이는 모습이 똑같아요.
- `src/admin/`: 관리자 화면 (편집기, 목록, 설정)
- `worker/`: 서버 (API, 로그인, 사진 저장)
- 사진 위치는 원본 사진을 기준으로 한 퍼센트 값(`crop`)으로 저장해요. 그래서 나중에 다시 열어서 고칠 수 있어요.
